# 課前準備：ChatGPT 桌面版與系統更新

查核日期：2026-10-04。請先完成 App 更新，再確認作業系統符合需求。課堂使用的是包含 Codex 的新版 ChatGPT 桌面版；只看到 ChatGPT Classic 或一般聊天介面，不代表已具備本課程所需的本機操作環境。

## 電腦需求

| 電腦 | 官方說明 | 本課程準備方式 |
|---|---|---|
| Mac | macOS 14 或以上，Apple Silicon（M1 或更新）或 Intel 處理器 | 安裝適合自己 Mac 的新版 ChatGPT，登入後確認可切換到 Codex |
| Windows | ChatGPT Windows 說明頁列 Windows 10 build 17763.0 或以上，x64 或 arm64；Codex 原生環境文件建議 Windows 11，近期完整更新的 Windows 10 僅盡力支援 | 課程以 Windows 11 為測試基準，不把舊版 ChatGPT 的最低安裝條件當成全部 Codex 功能的保證 |

來源：[OpenAI macOS 需求](https://help.openai.com/en/articles/9275200-downloading-the-chatgpt-macos-app)、[Windows App 說明](https://help.openai.com/en/articles/9982051-using-the-chatgpt-windows-app)、[Codex Windows 系統建議](https://learn.chatgpt.com/docs/windows/windows-sandbox)。

## 安裝或更新 ChatGPT App

統一從 [OpenAI 官方下載頁](https://chatgpt.com/download/) 取得新版 ChatGPT。下載頁另有 Classic 版本，這堂課請選包含 Work 與 Codex 的新版。已使用 Codex App 者可更新原 App；使用舊 ChatGPT 者依 App 提示下載新版，再登入原帳號。[官方遷移說明](https://help.openai.com/en/articles/20001276-moving-to-the-new-chatgpt-desktop-app)

### macOS

1. 開啟 ChatGPT 桌面版。
2. 在螢幕最上方的 App 選單中，選 Check for Updates（檢查更新）。
3. 若有更新，依提示安裝，完整結束 App 後重新開啟。
4. 再檢查一次，確認目前沒有可用更新。
5. 在左上角切換到 Codex，確認能選取本機工作區。

### Windows

1. 開啟新版 ChatGPT 桌面版。
2. 選 Menu → Check for Updates（選單 → 檢查更新）。
3. 安裝可用更新，完整結束後重新開啟，再檢查一次。
4. 如果是 Microsoft Store 管理的安裝版本，開啟 Microsoft Store，進入更新頁並按「檢查更新」；舊版介面可能顯示「程式庫 → 取得更新」。若仍是 Classic，回官方下載頁取得新版。
5. 確認能切換到 Codex 並選取本機工作區。

[OpenAI 的 App 更新步驟](https://help.openai.com/en/articles/20001516-managing-usage-with-gpt-6-astra-in-work-and-codex)、[Microsoft Store 更新說明](https://support.microsoft.com/zh-tw/accounts-billing/get-updates-for-apps-and-games-in-microsoft-store)。最新版以自己的 App 更新檢查結果為準，不以講義中的固定版本號判定；學校管理的電腦可能由管理者控制更新與功能權限。

## 如果作業系統也需要更新

先儲存工作並備份重要檔案，再安裝電腦提供的相容正式更新。更新 App 與更新作業系統是兩件事，完成其中一項不代表另一項也完成。上課前先做完並重新啟動，避免課堂中等待安裝。

- macOS：「蘋果選單 → 系統設定 → 一般 → 軟體更新」，依畫面按更新或升級。系統只會提供與該 Mac 相容的版本；顯示已是最新版仍可能是該機型可用的最後版本。[Apple 官方步驟](https://support.apple.com/zh-tw/108382)
- Windows 11：「開始 → 設定 → Windows Update → 檢查更新」，下載並安裝可用更新，依提示重新啟動。[Microsoft 官方步驟](https://support.microsoft.com/zh-tw/windows/deployment/updates-lifecycle/install-windows-updates)
